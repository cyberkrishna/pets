# Pet packs

Each subfolder here is a **pet pack** the app can switch between (tray → **Pet**,
or right-click the pet → **Next pet**). A pack is a folder containing a `pet.json`
and, for sprite pets, a `sheet.png`.

## Built-in pets

- `openpets-default/` — the **default** pet: the pixel pup from
  [OpenPets](https://github.com/alvinunreal/openpets) (MIT, see its CREDITS.txt).
  High-res frames, smooth-scaled, with dedicated walk rows for ambient strolls.
- `cat/`, `fox/`, `bunny/` — original chibi pixel animals with full per-state
  expressions (blinks, happy ^^, teary ><, wide-eyed waiting, head-tilt thinking).
  Generated by `node tools/make-animals.js`; each pack has a 4x `preview.png`.
- `aura/` — the original hand-drawn SVG pet. It uses `"render": "svg"` and has no
  sheet — the renderer draws it procedurally.

## Sprite pet format (`pet.json`)

```json
{
  "id": "slime",
  "name": "Green Slime",
  "render": "sprite",
  "sheet": "sheet.png",
  "frameWidth": 32,
  "frameHeight": 32,
  "scale": 4,
  "states": {
    "idle":    { "row": 0, "frames": 4, "durationMs": 160 },
    "review":  { "row": 1, "frames": 6, "durationMs": 120 },
    "running": { "row": 2, "frames": 6, "durationMs": 90  },
    "waiting": { "row": 3, "frames": 4, "durationMs": 180 },
    "waving":  { "row": 4, "frames": 4, "durationMs": 120 },
    "jumping": { "row": 5, "frames": 6, "durationMs": 90  },
    "failed":  { "row": 6, "frames": 4, "durationMs": 140 }
  }
}
```

### States

The animation states (ported from the OpenPets reaction model) are:
`idle, review, running, waiting, waving, jumping, failed`, plus optional
`running-left` / `running-right` walk rows used for ambient strolls (packs
without them fall back to `running`, then `idle`).
Agent **reactions** map onto them like this:

| reaction (webhook `status`)        | animation |
|------------------------------------|-----------|
| idle                               | idle      |
| thinking                           | review    |
| working / editing / running        | running   |
| testing / waiting                  | waiting   |
| waving                             | waving    |
| success / celebrating / done       | jumping   |
| error                              | failed    |

Any state you don't define falls back to `idle`, so a single-animation pet only
needs an `idle` entry.

### Frame addressing

A state is a strip of frames played in a loop. Two ways to point at frames:

- **Row form** — `{ "row": N, "frames": K, "durationMs": MS }` reads `K` frames
  left-to-right starting at column 0 of row `N` (cells are `frameWidth`×`frameHeight`).
- **Explicit form** — `{ "frames": [ {"x":0,"y":0}, {"x":32,"y":0}, ... ], "durationMs": MS }`
  for irregular sheets where frames aren't a clean row.

`durationMs` is **per frame**. Optional extras per state / pack:

- `"iterations": N` (per state) — play the strip N times, then revert to `idle`
  (OpenPets-style one-shot reactions like waving/jumping/failed).
- `"smooth": true` (top level) — bilinear scaling instead of pixelated
  nearest-neighbour; use for high-resolution sheets that are scaled *down*.

`scale` is the zoom applied when drawing (4 = a 32px sprite shown at 128px;
fractions like 0.72 are fine for high-res sheets).

## Adding your own

1. Drop a folder `pets/<your-id>/` with `sheet.png` + `pet.json`.
2. Restart the app. It appears in the tray **Pet** submenu automatically.

## Generating / fetching packs

- `node tools/make-placeholder.js` — regenerate the simple placeholder packs.
- `node tools/fetch-pets.js` — generate placeholders **and** download CC0 art
  (currently a CC0 slime from OpenGameArt). Downloads fall back to a placeholder
  if offline. CC0 needs no attribution; sources are still recorded in each
  pack's `CREDITS.txt`.
